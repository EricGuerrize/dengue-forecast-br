QUALIDADE DA PREVISÃO

Erro em dados anteriores

O erro mostra, em média, quantos casos separaram a previsão do número registrado. Quanto menor, melhor. Cada método pode ter sido avaliado em uma quantidade diferente de semanas.

VALIDAÇÃO DO ALERTA

Como o alerta vermelho se saiu

Os percentuais usam previsões feitas para semanas que já passaram. Em cada uma, a comparação considerou apenas os dados conhecidos naquela época.

Entenda os números

Os casos registrados vêm do InfoDengue e a população vem do IBGE. A lista mostra apenas municípios com 105 semanas seguidas de casos e dados suficientes para fazer e conferir as previsões de 4 e 8 semanas. Chuva e temperatura são usadas quando há dados de uma estação do INMET próxima.

A previsão estima quantos casos podem ser registrados daqui a 4 ou 8 semanas. Para saber quanto ela costuma errar, repetimos o cálculo para semanas passadas e comparamos com os casos que foram registrados depois.

A faixa de alerta compara a previsão com as semanas anteriores do mesmo município. “Mediana” é o valor que divide essas semanas ao meio. “Percentil 90” é um patamar que só uma em cada dez semanas ultrapassa. São comparações locais, não níveis oficiais de alerta.

A estimativa corrigida tenta compensar notificações que chegam atrasadas. O cálculo de atraso usa dados de outro sistema de saúde, o SIVEP-Gripe, e deve ser lido com cuidado. Esta página só muda quando uma nova cópia dos dados é publicada. Consulte também os boletins da SES e da vigilância local.
